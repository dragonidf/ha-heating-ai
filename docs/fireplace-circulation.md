# Циркуляція каміна

`delta` — різниця між датчиком каміна й температурою керування. Тренд — зміна цієї різниці за доступними пробами останніх 30 хвилин, у °C/год. Температура датчика не доводить наявність полум’я: фази описують доступне тепло.

| Умова | Фаза / автоматичний запит |
|---|---|
| delta ≥ 2 °C, тренд > +0.8 °C/год | Розпалювання; нового запуску циркуляції немає |
| delta ≥ 5 °C | Горить; циркуляція потрібна |
| delta ≥ 10 °C без тренду згасання | Інтенсивно горить; удень рівень 3 |
| Тренд < −0.8 °C/год | Згасає; новий запуск нижче 5 °C не відбувається |
| Після запуску delta ≥ 3 °C | Запит утримується, навіть якщо нижче порога запуску 5 °C |
| delta < 3 °C протягом 5 хвилин | Запит знімається; контролер зупиняє запущений ним вентилятор |
| delta < 4 °C та тренд ≤ −2 °C/год | Запит знімається без витримки |

При згасанні навіть із delta ≥ 10 °C обирається звичайний денний рівень: великий залишковий перепад не означає інтенсивне горіння. Повернення до 3 °C скидає таймер вимкнення. Невідомий/застарілий датчик прибирає автоматичний запит; перерва між циклами понад 90 секунд скидає відлік безперервного низького перепаду. Коротке перезавантаження зі збереженим станом не скидає таймер.

## Три рівні

| Рівень | Helper / параметр локального YAML | Вибір |
|---|---|---|
| 1 · Ніч | `input_number.heating_fan_night_limit` / `fan_night_limit` | 23:00–07:00, незалежно від інтенсивності |
| 2 · День стандарт | `input_number.heating_fan_speed` / `fan_speed` | Решта денних запитів |
| 3 · День інтенсив | `input_number.heating_fan_intense_speed` / `fan_intense_speed` | Удень при «Інтенсивно горить» |

Нічна швидкість не перевищує стандартну, інтенсивна — не нижча за стандартну. Межі команд — 1–100%; для нового helper рекомендовано 10–100%, крок 1%, режим box. Створювати helper через **Налаштування → Пристрої та служби → Помічники → Число**, не через `.storage`. Без заданого `initial` HA відновлює останнє значення після перезапуску. На поточному встановленні helper підготовлено зі значенням 60%, нічні 38% й денні 42% збережено. На інших встановленнях без helper резервне значення — 60% (щонайменше стандартна швидкість).

HACS доставляє новий код і поле панелі; локальний YAML не потрібно змінювати для стандартної назви helper. Для іншого entity_id задати `fan_intense_speed` у локальній конфігурації AppDaemon. Оновлення встановлюється чинним автоматичним координатором.

## Ручне керування й діагностика

Явний «Ручний запуск» і тимчасовий нічний запит залишаються окремими причинами роботи навіть без каміна. Вентилятор, запущений користувачем поза контролером, не привласнюється автоматикою лише через зміну швидкості; режим «Зупинити» явно зупиняє його. Дозвіл команд, перевірки резервного живлення й доступності вентилятора залишаються чинними.

`sensor.heating_fan` публікує `request_source`, `selected_level`, `level_percentages`, `controller_owned`, `manual_running`. Атрибут `cooldown_remaining_seconds` сенсора `sensor.heating_fireplace` показує залишок витримки. Ці атрибути доступні у подробицях панелі й дозволяють відрізнити затримку зупинки від ручного запуску.
